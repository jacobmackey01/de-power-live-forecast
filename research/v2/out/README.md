# What these files are

Output of the scripts in `research/v2/`, kept as they were written.

**Nothing here is a result.** `rehearsal_aug_nov_2026.md` and
`rehearsal_last_winter.md` were produced by running the production seal and
scoring code over past days. They use the live report's layout, so they say
"judged against the criteria frozen in PREREGISTRATION_PHASE2.md" and show
PASS against each call. Read that as the report's logic applied to development
data. The periods were looked at while the design was chosen, the weather they
used was better than a live seal would have had (see `../README.md`), and
neither file is part of the phase-2 record.

The phase-2 record is `predictions/v2/` and `results/v2/`, and nothing else.
